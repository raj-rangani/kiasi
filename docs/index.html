How the cost is cut

Less goes in, so less is re-sent.

Claude Code is a loop. Every step sends the whole context to the model, runs one tool, appends the output, and goes again. Your bill is the context size added up over every step. Kiasi hooks into that loop in two places: what enters the context, and how long the turn runs.

An example turn: an npm install log, a test run that fails three times, a few file reads, 70 steps.

bill = context at step 1 + context at step 2 + … + context at the last step. Kiasi lowers each term and removes the last ones. Nothing is summarised by a model and nothing leaves your machine.

Install

Three steps, about a minute.

Two pastes and a restart. Nothing to build, nothing to sign up for.

  1. 1

    Install the plugin

    20 s

    In Claude Code:

    /plugin marketplace add raj-rangani/kiasi
/plugin install kiasi@kiasi
  2. 2

    Add two settings

    30 s

    In the env block of ~/.claude/settings.json. Kiasi reminds you at session start if either is missing.

    "CLAUDE_CODE_AUTO_COMPACT_WINDOW": "200000",
"CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1"

    The first compacts at 200k instead of the full window and is the biggest single lever. The second turns on the experimental pruner and search.

  3. 3

    Restart, then work as usual

    10 s

    Run /kiasi:limits setup once so the dashboard can show your plan limits. The dashboard starts itself with every session at 127.0.0.1:8787.

Does cutting output make Claude miss things?

Cuts keep the head and tail and leave a [kiasi kept …] or [kiasi trimmed …] marker naming the saved file with the full text. Claude reads that file by path when the cut part matters. File reads, range commands and diffs are never cut, so code quality does not depend on the cap.

Where does the data go, and how long does it stay?

All state goes to ${CLAUDE_PLUGIN_DATA}, normally under ~/.claude/plugins/data/: event log, saved pastes and outputs, notes, session records, gzipped reports and a per-day history that outlives Claude Code's own transcript retention.

A background cleanup moves a saved file, gzipped, to trash/ once it and its session have been unused for 7 days (pastes 14), and deletes trash 7 days later. It only reports for its first week, never touches the running session or the last 24 hours, logs every move, and python3 scripts/cleanup.py --restore puts files back. Set KIASI_CLEANUP to report, trash or off.

Keeping the dashboard up

Nothing to do: every session start checks for a dashboard on 127.0.0.1:8787 and starts one detached when none answers, so it outlives the session and keeps rebuilding every 30 minutes. Set KIASI_DASHBOARD=off in the env block to disable that.

To have it up before the first session, on Linux use a systemd user unit with Environment=CLAUDE_PLUGIN_DATA=<your data directory>, ExecStart=/usr/bin/python3 <plugin root>/scripts/dashboard.py 8787 and Restart=always.

Plan limits and the status line

/kiasi:limits setup copies scripts/statusline.py to ~/.claude/kiasi/ and points statusLine in ~/.claude/settings.json at it, backing the file up once. A status line you already had keeps running inside it. Kiasi never calls the usage API itself; the limits come from what Claude Code hands the status line.

Experimental: function hooks

The compaction pruner and mcp__kiasi__search use Claude Code's early-access function-hook API (2.1.282+), which may break on an engine update. Kiasi is fully useful without it: the seven classic hooks and the dashboard need only Python.

Requirements, tests, uninstall
  • Claude Code 2.1.283+
  • Python 3.8+, standard library only (tested on 3.10 and 3.11)
  • Linux (tested) or macOS (expected to work). Windows is not supported.
  • Node 18+ only for the experimental function hooks
python3 -m unittest discover -s tests   # hook handlers, reports, dashboard
claude plugin test .                     # hooks/*.test.ts on the real engine
claude plugin validate .                 # manifest, marketplace and hooks.json

Uninstall: run /kiasi:limits remove if you set up the status line, then /plugin uninstall kiasi.
