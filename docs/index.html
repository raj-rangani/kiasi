01 · The cost

Less goes in, so less is re-sent.

Claude Code is a loop. Every step sends the whole context to the model, runs one tool and appends its output. The bill is that context, summed over the turn. Kiasi shrinks what enters and ends turns sooner.

Every step re-sends everything. An npm install log that lands at step 3 is paid for again at step 4, 5, 6, all the way to the end of the turn.

Kiasi shrinks what enters. Each tool output is cleaned and capped at 12,000 chars before it joins the context. A file read twice becomes a pointer. The line climbs slower from the first step.

And ends the turn sooner. A warning at 30 tool calls, a stop at 60, and a loop check that catches the same call failing three times. The bill is the area under each line.

bill = context at step 1 + … + context at the last step. Kiasi lowers each term and removes the last ones.

Four levers, all on the loop.

Each one is a hook sitting on an edge of the cycle. Nothing is decided by a model.

  • Less enters. Every tool output is cleaned and capped before it joins the context. The full text stays on disk.lowers the line
  • Nothing enters twice. An unchanged file read again becomes a pointer. A long paste becomes a path.lowers the line
  • Fewer steps. A warning at 30 tool calls, a stop at 60. Three identical failures tell Claude to rethink.shortens the turn
  • A small restart. At compaction old tool output is pruned, your words stay verbatim, and the task state is re-injected.resets the line

02 · What it fixes

Six leaks, six rules.

Each rule is a Claude Code hook with a fixed threshold you can change. The hook it runs on is named beside each one.

  • Output cap and cleaning. Over 12,000 chars is cut, progress bars and repeated lines are stripped, the full text is saved.
  • Turn budget and loop check. Warned at 30 tool calls, stopped at 60. The same call failing three times tells Claude to rethink.
  • Re-read skip. The same file, unchanged, returns a pointer to the copy already in context.
  • Paste manager. Over 4,000 chars is saved to disk; over 40,000 is refused and you resend with the path.
  • Pruner and state. At compaction your prompts and Claude's replies stay word for word; task, edited files and failing commands are re-injected.
  • Local dashboard. Every action Kiasi took, the tokens it kept off your limit, and your 5-hour and weekly limits.

04 · Install

Three steps, about a minute.

Two pastes and a restart. Nothing to build, nothing to sign up for. Requires Claude Code 2.1.283+ and Python 3.8+, standard library only.

1Step 1 · 20 s

Install the plugin

In Claude Code:

Claude Code
/plugin marketplace add raj-rangani/kiasi
/plugin install kiasi@kiasi
2Step 2 · 30 s

Add two settings

In the env block of ~/.claude/settings.json. The first compacts at 200k instead of the full window. The second turns on the experimental pruner and search.

~/.claude/settings.json · env
"CLAUDE_CODE_AUTO_COMPACT_WINDOW": "200000",
"CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1"
3Step 3 · 10 s

Restart, then work as usual

Run this once so the dashboard can show your plan limits. The dashboard starts itself with every session at 127.0.0.1:8787.

Claude Code
/kiasi:limits setup

05 · Privacy

Everything stays on your machine.

Kiasi reads your local transcripts and writes to its own folder. There is no account and no upload.

  • No network calls. Not one. Python standard library, no dependencies, nothing phoning home.
  • No prompt text logged. Reports hold counts and sizes, never what you typed.
  • Localhost only. The dashboard listens on 127.0.0.1 and refuses other host names.
  • Nothing lost. Every cut output and refused paste is saved in full and found again by search.

Does cutting output make Claude miss things?

Cuts keep the head and tail and leave a [kiasi kept …] or [kiasi trimmed …] marker naming the saved file with the full text. Claude reads that file by path when the cut part matters. File reads, range commands and diffs are never cut, so code quality does not depend on the cap.

Where does the data go, and how long does it stay?

All state goes to ${CLAUDE_PLUGIN_DATA}, normally under ~/.claude/plugins/data/: event log, saved pastes and outputs, notes, session records, gzipped reports and a per-day history that outlives Claude Code's own transcript retention.

A background cleanup moves a saved file, gzipped, to trash/ once it and its session have been unused for 7 days (pastes 14), and deletes trash 7 days later. It only reports for its first week, never touches the running session or the last 24 hours, logs every move, and python3 scripts/cleanup.py --restore puts files back. Set KIASI_CLEANUP to report, trash or off.

Keeping the dashboard up

Nothing to do: every session start checks for a dashboard on 127.0.0.1:8787 and starts one detached when none answers, so it outlives the session and keeps rebuilding every 30 minutes. Set KIASI_DASHBOARD=off in the env block to disable that.

To have it up before the first session, on Linux use a systemd user unit with Environment=CLAUDE_PLUGIN_DATA=<your data directory>, ExecStart=/usr/bin/python3 <plugin root>/scripts/dashboard.py 8787 and Restart=always.

Plan limits and the status line

/kiasi:limits setup copies scripts/statusline.py to ~/.claude/kiasi/ and points statusLine in ~/.claude/settings.json at it, backing the file up once. A status line you already had keeps running inside it. Kiasi never calls the usage API itself; the limits come from what Claude Code hands the status line.

Experimental: function hooks

The compaction pruner and mcp__kiasi__search use Claude Code's early-access function-hook API (2.1.282+), which may break on an engine update. Kiasi is fully useful without it: the seven classic hooks and the dashboard need only Python.

Requirements, tests, uninstall
  • Claude Code 2.1.283+
  • Python 3.8+, standard library only (tested on 3.10 and 3.11)
  • Linux (tested) or macOS (expected to work). Windows is not supported.
  • Node 18+ only for the experimental function hooks
python3 -m unittest discover -s tests   # hook handlers, reports, dashboard
claude plugin test .                     # hooks/*.test.ts on the real engine
claude plugin validate .                 # manifest, marketplace and hooks.json

Uninstall: run /kiasi:limits remove if you set up the status line, then /plugin uninstall kiasi.
