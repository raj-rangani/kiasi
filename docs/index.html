[04]How it worksthe messages Claude actually gets

Fixed rules, no model in the loop.

Kiasi hooks into Claude Code's tool calls. Every rule is a threshold, not a judgement, and the full text is always on disk.

[05]What it doesindex of parts

Same work. More week.

Beyond the three rules, the parts that keep a long session small and leave the full text where Claude can find it.

  1. A

    Run, distill, fetch

    A build, a test run, a web page or a big file goes through a tool that saves the full text and returns only the digest or the matching lines.

    mcp__kiasi__run · distill · fetch · search
  2. B

    Status line and limits

    One command adds your 5-hour and weekly limits, context size and step count to the status line, after whatever you already had.

    /kiasi:limits setup
  3. C

    Compaction that keeps the task

    At compaction your prompts and Claude's replies stay word for word. Old tool output goes. The task, edited files and failing commands come back.

    session.compact
  4. D

    Paste manager

    A paste over 4,000 chars is saved to disk and replaced by a path Claude can search. Over 40,000 is refused with the path to resend, so one stray log never fills the window.

    UserPromptSubmit
  5. E

    Cleans up after itself

    Saved outputs and pastes older than seven days are compressed, then dropped. The data folder stays small on its own, and a restore command brings a day back.

    daily, at session start

[09]Installabout a minute

Make this week's limit last.

Three lines and about a minute, in the terminal or VS Code. Nothing to build, nothing to sign up for, and your first before-and-after shows up the next day.

  1. Install the plugin

    In a terminal, two lines. In the VS Code extension, one button, or /plugins in the prompt box. Both are beside this.

  2. Restart, then one command

    Run /kiasi:limits setup once. It writes the two settings Kiasi needs and adds your plan limits to the status line. The dashboard starts itself with every session at 127.0.0.1:8787.

  3. Come back tomorrow

    The first before-and-after needs a day of sessions. The overview then sets your days with Kiasi beside your days before it.

[10]Questionsasked first

What developers ask first.

Does Claude lose information it needs?

No text is thrown away. A cut output is saved in full with a path, and Claude is told where it is and how to search it. A skipped re-read points at the copy already in context. If Claude needs more, it reads the file by path.

How is this different from rtk or caveman?

rtk rewrites shell commands so their output is shorter, and caveman has Claude write shorter replies. JetBrains ran both through paired A/B tests on Claude Code and found that most of the advertised saving did not reach the bill (their rtk write-up).

Two differences. Kiasi works beyond the shell: the skip for an unchanged file is on Read, and the caps cover MCP results, web fetches and pastes. And Kiasi's benchmark is measured against what Claude Code alone sends, including the cases where Claude Code alone sends less. Kiasi has not been through a paired test like JetBrains' yet; that is the next benchmark.

Does anything leave my machine?

No. Kiasi is Python standard library with no dependencies and makes no network calls. Reports hold counts and sizes, never what you typed. The dashboard listens on 127.0.0.1 only and refuses other host names.

Does it slow Claude Code down?

Each hook runs in milliseconds on the tool output it is given. Long commands are the ones that get faster, because a 3,000-line log no longer rides along on every later step of the turn.

What does it change in my settings?

Two keys in ~/.claude/settings.json: the compaction window at 200k and the pruner switch, plus a status line entry added after whatever you had. /plugin uninstall kiasi@kiasi puts both back.

Which plans and versions does it need?

Claude Code 2.1.283 or newer and Python 3.8 or newer. Any plan: the weekly-limit readout works on Pro and Max, and the context savings apply to API billing too.

How do I know it worked for me?

Open the dashboard the next day. It compares your context per request with your own days before Kiasi, read from your transcripts. The Your month panel makes a card you can post on this page.
